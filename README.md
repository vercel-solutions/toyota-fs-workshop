# Toyota Financial Services — Next.js Workshop

Hands-on exercises for the Next.js Foundations & Performance workshop, delivered
by Vercel Professional Services.

Every exercise is built around the **TFS Storefront** — the AI-assisted Toyota
vehicle marketplace — so the patterns you practice here map directly onto the
product you are shipping.

## Getting Started

```bash
pnpm install
```

## Exercises

- [`react`](exercises/react) — [Slides](toyota-fs-workshop.vercel.app/react)
- [`fundamentals`](exercises/fundamentals) — [Slides](toyota-fs-workshop.vercel.app/fundamentals)

> **Note:** All exercises run on port 3000. Only run one exercise at a time.

Run a single exercise:

```bash
pnpm --filter @workshop/<exercise-name>-exercise dev
```
